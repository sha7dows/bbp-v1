# 上下文反馈第二轮

所有代码和实验在服务器 /root/TRY；本地只承担SSH通道。旧结果与源码快照保留。
本轮无成员编辑，不改变原候选图、不新增关联，避免把压缩量差异混入反馈效果。

## 模式
- bbp：关闭反馈。
- node_control：原投影节点经残差适配器辅助评分。
- node_detach：相同适配器使用冻结的第一层HGNN试探节点表示。
- edge_control：共享5h输入评分器，输入原边表示、所选边按STC/User/Mention类型的全局均值和所选边整体均值。
- edge_context：相同评分器，将三种类型全局均值替换为候选边自己的Jaccard邻域聚合。初选决定哪些邻居发送信息，全部候选均可接收并重新被选回。

邻域上下文冻结，原边表示与评分器可以接收任务梯度。行为残差固定为0.25*tanh(MLP)，输出层零初始化。原始覆盖核不随评分训练变化。原始分类型覆盖逻辑保留，但本轮固定K试验不以尾部覆盖阈值作为硬约束。

## 预定协议
先以第一折、seed42、8轮比较五组；按最后3轮平均正类F1、再按AUROC，在node_detach与edge_context中选候选。
第二折采用候选、匹配容量控制与基线，在训练种子42/43下分别跑12轮。
数据划分种子始终42，Louvain种子始终42；训练种子只改变初始化、Dropout及训练顺序等训练随机性。
主比较固定第12轮；同时展示末3轮均值。逐轮预测与last/best检查点全部保存。
所有组逐会话保留ceil(0.7E)条边、相同初始化和样本顺序，额外Gumbel关闭。
验证集不调阈值，统一0.5。最终194会话不评估。

## 局限
两个开发折是同一开发集轮换，存在第一折训练与第二折验证重叠，因此是开发阶段复核，不是新的独立测试集。
两个训练种子不足以建立训练方差结论。配对会话bootstrap只描述给定模型下的会话抽样不确定性。
不把最佳轮次验证指标称作独立测试性能，也不把额外评分容量的收益归因于行为关系。
本轮不是原robust_adaptive五折20轮协议的替代结论。
