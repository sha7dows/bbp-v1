# BBP 预算选择与超图结构学习：研究建议

调研日期：2026-11-09。范围为相关原始论文的定向检索，不是穷尽综述。用户确认 HSL 指 Cai 等人的 IJCAI 2022 论文。训练代码未修改。

## 1. 当前实现与 HSL 的边界

当前模型在 `bbp_behm/model.py:113` 先投影原始节点，在 HGNN 前执行 Selector，随后才调用主干。分类损失已经通过直通掩码联合训练选择器和编码器。因而不能声称当前模型完全没有结构—表征协同。

当前缺少：把本次 HGNN/GCN 传播产生的结构上下文显式输入下一轮结构决策。评分阶段的投影节点不包含当前所选拓扑传播结果。

HSL 原论文 §3.3–3.5：超边采样、关联节点采样（包括缺失关联补充）、原始/优化结构间的边内对比学习。超边存在概率是边特定的可训练参数；成员采样概率由节点与边表示预测。其“双向增强”不是额外命名的双向网络，而是结构优化与表示学习的互相促进。

HSL 实验是 transductive 半监督节点分类；当前是跨会话的会话分类。迁移时需设计对新会话适用的共享评分函数，不能为测试会话单独拟合自由掩码参数。

## 2. 建议优先验证的缺口：代表覆盖不等于关系保持

当前代表矩阵仅在同类型内部构建，取结构 Jaccard、原始语义均值相似度、结构统计核的等权平均。后续 IBG 却允许不同类型超边之间通过内容节点重叠相连。

反例：

- STC 边 e={1,...,10}；STC 边 f={1,...,9,11}。
- User 边 g={10,12}。
- J(e,f)=9/11≈0.818；若语义核和统计核均为 1，则 R(e,f)=31/33≈0.939。
- J(e,g)=1/11，J(f,g)=0。

保留 f,g 可以让 e 的单边代表覆盖很高，但原始路径 f—e—g 变为两个孤立行为节点。这个反例只说明当前覆盖指标不能保证 IBG 关系保留，不说明真实数据已经因此产生性能损失。

真实数据第一步应量化：按当前代表映射，把删除边涉及的跨类型关系投影到保留边，再检查关系丢失、权重偏差、连通分量与预测变化。不能只比较原图与删点后子图的原始边数。

## 3. 方案 A：预算约束下的结构—表示反馈

建议流程：原始候选 H0 → 初选 S0 → 轻量传播 → 在全部原候选 E0 上重评分 → 使用相同预算/覆盖规则得到 S1 → 最终主干分类。

可以用初选传播得到的节点上下文重新池化所有候选边：

    h_e = mean_{v in e} [Z_v || X_N,v^pilot]
    s_e^(1) = s_e^(0) + alpha * MLP([h_e || c_session^pilot || stats_e])

第一版只用 HGNN 试探传播即可验证局部反馈；如果加入 IBG/社区反馈，再单独验证其额外价值与开销。不能只对 kept 边重评分，否则被误删边无法回流。

建议先用一次反馈、stop-gradient 试探上下文作为稳定实现起点，随后对比完整反传。原始覆盖核先保持固定；任务分数可学习，覆盖度量不要随评分器一起自由变化。训练和推理使用同样的固定轮数，不依赖训练标签进行推理重选。

这属于 HSL 思路的迁移；“多跑一轮”本身不构成充分新颖性。需要结合预算、分类型覆盖与行为关系保持提出具体差异。

## 4. 方案 B：保护跨类型关系的代表选择

第一版可给每条候选边补充与不同类型邻居的关系轮廓：各类型关联总量、关系分布、不同邻居类型数，以及可选的多跳结构 sketch。现有 `use_ibg_centrality` 只有一个加权度标量，不能区分同度数但邻域角色不同的边。

代表边除了内容相近，还应具有相似关系角色。可以用固定结构轮廓补充覆盖核，或在贪心效用中加入关系保持增益，先分别消融。

更完整的版本：定义从全部候选边到同类型保留代表边的分配 P（E×K）；从可靠参考 IBG 的 W 构造 P^T W P，剔除或单独处理对角线，并按簇质量归一化，再与保留结构的关系矩阵或消息传播算子比较。

    L_rel = D(Norm(offdiag(P^T W_ref P)), Norm(W_kept))

这是设计草案，不是已证明的界。若用于训练，P 与 W_kept 必须通过软门控或直通代理连接评分器；对完全硬化、detach 的图计算损失并不会训练选择器。W_ref 也不能无条件视为真值，以免保留输入噪声。应先比较静态先验、去噪参考和任务条件参考。

社区结构引导粗化已有历史工作，因此不能声称“首次利用社区优化超图”。潜在区别在于：异质行为类型、整边预算、代表覆盖与 BeHM 的跨类型 IBG 传播联合考虑。

## 5. 方案 C：有限制地修复 STC 成员

HSL 的增删关联可用于处理构图漏连，但需要保持行为语义。User/Mention 边的定义有明确业务约束，不宜无条件允许任意加成员。若试验，应优先只修复 STC，限制同一会话、满足时间与语义先验、限制编辑数量，并记录原始来源和修复来源。

这会从“整边选择”扩大为“选择与结构修复”，影响覆盖矩阵、IBG 和解释导出，需要重新定义三者使用原结构还是修复结构。建议作为后续方向，不与首轮预算实验同时引入。

## 6. 其他方向与取舍

- 信息瓶颈：已有 DeepHGSL；仅添加 KL/稀疏损失不足以作为独立贡献。可以用于概念解释，但必须对应真实随机变量、先验和变分界，不能把任意正则叫作互信息。
- 结构对比：HSL、HyperGCL、MHSL、SHSL 均有相关机制。欺凌会话内不同内容可能语义不同，不应无差别强制所有邻居相同；可对齐相同节点跨视图表示或会话表示，并检验负样本误设。
- 真实计算预算：边数预算不等于运行开销，可考虑 incidence 数、IBG 关系数或实测延迟。必须包含评分、覆盖、试探传播、社区发现的全部开销。
- MDL/backboning：可替代单纯 subset 精简作为非学习基线或结构先验；结构冗余不必然等于任务无用，不能直接把 MDL 最短结构当成欺凌检测最优结构。

## 7. 最小实验路线

固定同一数据划分、主干、种子、训练预算、阈值协议；最终测试集不参与选型。

| 版本 | 目的 |
|---|---|
| Full BeHM | 完整候选结构参考 |
| 随机 / 结构去重 / 固定预算任务 Top-K | 区分规则精简和学习选择的收益 |
| 当前 robust BBP | 当前主要基线 |
| BBP + 一次表征反馈 | 验证显式反馈 |
| BBP + 关系保持 | 验证跨类型关系保留 |
| BBP + 反馈 + 关系保持 | 验证组合是否互补 |
| 同参数量 MLP 或同计算量双前向控制 | 排除参数与算力增加带来的混淆 |

固定逐会话 K 做机制比较，再画可变预算 Pareto 曲线；如果固定 K 下覆盖无法达到阈值，报告不可行/未达标率。仅限制平均保留率并不等价于逐会话同预算。

评估：正类 F1/Recall、Macro-F1、AUROC；边与 incidence 保留率、IBG 规模；基于代表映射的关系失真、各类尾部覆盖；全流程训练/推理时间与显存。不同节点集上的社区标签不能直接做 NMI，需先用代表映射提升到共同候选集合。折不是独立重复种子，额外用多种子和按会话 bootstrap 或合适配对分析估计不确定性。
