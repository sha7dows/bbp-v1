# 大STC受约束分解

所有代码写入、检查、训练和诊断均在 /root/TRY 服务器执行。原始文件备份为 .backups/pre_split_20261109.tgz。

## 机制

原始候选图 → BBP选择父边 → 对符合条件的STC父边进行二分 → 子边进入HGNN和IBG → 会话分类。

BBP评分、原覆盖核及预算始终读取原候选父边。每会话保留 ceil(0.7 * E) 个父边；分解不会为选择器增加候选名额。默认 none 与原BBP的离散掩码完全一致，logits 容差1e-6。

语义混杂度 D(e) = n/(n-1) * (1 - ||mean(normalize(x_v))||²)，等于两两余弦距离均值。规模门槛为训练折STC规模p75且至少16；混杂度门槛为训练折大STC的D中位数；二分后按子边规模加权的D至少降低0.01。所有门槛不读取验证标签，原始BERT特征不更新分区。这是静态结构分解实验，不是HSL完整复现，也尚无表示反馈驱动的动态分区。

分区在去掉共享锚点后的成员上进行确定性的平衡语义二分：近似最远原型方向排序后均分。最多四个同时属于User/Mention边的成员作为共享锚点，按非STC关联度优先、语义中心性和节点号打破并列，复制到两个子边；复制数量不超过父边成员数10%。其他成员只进入一个子边。保留所有User/Mention整边及所有父边成员，禁止增加父边以外的成员；每个子边至少2个成员。保护的是选出的关键锚点，并非所有共享节点均被复制。

子边 source_ids 追加稳定的会话号、原始局部父边号、子边号；原来源不删除。构造强度继承父边并明确作为历史属性，其余规模、时间和用户统计重新计算。父边与传播边编号独立，批组装时重新编号；成员始终是全局节点号。

## 预定实验

none：保持父边传播。
random：在语义规则筛出的同一批父边上随机均分非锚点成员。
semantic：按语义方向均分。

random与semantic逐父边使用相同触发条件、锚点、子边数量、子边规模和总关联数量，随机分区由父边标识确定且不消耗训练随机数。门控使用语义可分解性对两组共同生效，随机组仅检验分区质量，不代表完全无语义先验的方法。

三组参数量相同，初始化、训练顺序、优化器、父边候选及固定70%预算相同；端到端梯度可以让后期实际选择的父边不同，因此逐轮记录实际传播边数和关联数，不宣称不同训练模型实际传播成本处处严格相同。另有同一父边掩码的严格配对约束检查。

固定最终194会话不评估；开发集776会话使用原有五折划分。第一折seed42运行8轮，第二折seed42与43各12轮，全部三组均完成，不按结果筛掉对照或改轮次。主要复核看第二折固定第12轮和最后3轮均值；第一折仅作探索。第二折此前已用于上下文研究，属于开发集复核，不是独立最终测试。训练正类权重1.5、置信度权重、模型/优化器参数沿用服务器配置；关闭额外Gumbel噪声。

记录分类F1/AUROC、精确率召回率、父边保留量、实际子边数量与关联成本、平均与最大边规模、父边覆盖及真实子边同类型Jaccard覆盖、耗时显存、每轮预测及末轮检查点。不会用父边成员并集可重构来声称HGNN传播等价。单折最多两个种子，配对bootstrap仅描述给定模型在该验证集上的不确定性，不能估计完整训练方差或证明论文新颖性。

三个折/种子由独立进程并发执行，随机状态隔离但共享GPU。耗时仅记录实际运行成本，不能据此给出严格速度优劣结论。
